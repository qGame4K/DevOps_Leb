# VS Code vs терминал для работы с Git

Удобное в VS Code:
1. Наглядный diff файла прямо во вкладке — сразу видно, что именно изменилось, без чтения вывода `git diff` построчно.
2. История коммитов и панель Source Control — можно кликом посмотреть, кто и когда что менял (особенно удобно с GitLens).
3. Коммит через UI: ввёл сообщение, нажал ✓ — не нужно помнить точный синтаксис `git commit -m`.

Удобнее в терминале:
1. Push/pull и работа с ветками на сервере по SSH — там нет графического интерфейса, только CLI, поэтому важно уметь делать это руками, а не полагаться на кнопки IDE.
