# Мои цели на семестр

1. Уверенно работать с Git в терминале: ветвление, merge, rebase, разрешение конфликтов — без опоры на UI IDE.
2. Освоить Docker: научиться писать Dockerfile и docker-compose для собственных учебных проектов.
3. Настроить рабочий CI/CD-пайплайн на GitHub Actions — от линтера и тестов до автодеплоя.
